# Objectives & Rewards

The objective in Grid Adventure is to complete the following tasks:

- Collect all gems present (if any).
- Move to the exit tile.

## Reward

- Each turn taken by the agent incurs a reward of **-3**, except if the agent is on the exit tile at the end of the turn.
- Each coin collected provides a reward of **+5**.

## Optimal solution

An optimal solution achieves all objectives while maximising the total reward. There is no requirement to finish with non-negative reward or maximum HP. To maximize reward, the agent can either complete the objectives in fewer turns or collect more coins.
