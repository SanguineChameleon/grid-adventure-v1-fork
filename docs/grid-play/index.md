# Grid Play

**Grid Play** is a browser-based playground for Grid Adventure. It is the tool you use to run and debug your agent — as well as to play levels yourself and design new ones.

Grid Play lets you:

- **Play** levels with keyboard or button controls
- **Configure** levels with adjustable parameters, or build your own
- **Test your agent** through step-by-step execution, seeing exactly what it perceives and decides

## The three tabs

Grid Play is organized into three tabs:

| Tab | Purpose |
|-----|---------|
| [**Game**](game.md) | Play the level, control the agent (buttons, keyboard, or your code), and view status |
| [**Config**](config.md) | Choose and configure the level |
| [**State**](state.md) | Inspect the full internal game state for debugging |

## Quick start

1. Open the **[Config](config.md)** tab and select a level source.
2. Adjust the parameters as desired and click **Save**.
3. Switch to the **[Game](game.md)** tab to start playing.
4. Use the keyboard or buttons to move and interact — or load your agent under **Code** control to watch it play.
